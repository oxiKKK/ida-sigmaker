# oxiKKK-ida-sigmaker

Improved Python sigmaker plugin for IDA 9.X originally made by [mahmoudimus](https://github.com/mahmoudimus).

## Improvements

- [Linux] python crash fix when the pattern search went out of function scope and the option "Continue when leaving function scope" was not set.
